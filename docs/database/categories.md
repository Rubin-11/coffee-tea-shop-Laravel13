# Категории

Миграция: `database/migrations/2026_08_10_190307_create_categories_table.php`
Модель: `app/Models/Category.php`

## Схема

| Колонка | Тип | Примечание |
|---|---|---|
| `name` | string, unique | |
| `slug` | string, unique | используется в URL (`/catalog/{slug}`) |
| `description` | string | |
| `image` | string, nullable | |
| `is_active` | boolean, default `true` | в коде пока не проверяется (нет `where('is_active', true)` в запросах) |
| `parent_id` | nullable FK → `categories.id`, `nullOnDelete` | делает таблицу деревом, см. ниже |

`nullOnDelete` на `parent_id`: если удалить родительскую категорию, у её детей `parent_id`
станет `NULL` (они не удаляются, а становятся категориями верхнего уровня) — так БД не
даст случайно повалить всё дерево при удалении одной категории.

## Связи в модели

```php
parent(): BelongsTo    // родительская категория (null у категорий верхнего уровня)
children(): HasMany    // прямые подкатегории
products(): HasMany    // товары этой категории (напрямую, без учёта children)
```

Важно: `products()` отдаёт только товары с `category_id`, равным id именно этой категории —
товары дочерних категорий сюда не попадают автоматически. Для "товары категории + всех её
подкатегорий" собирают id вручную (см. ниже про `CatalogController`).

## Реальные данные (`CategorySeeder`)

4 категории верхнего уровня (`parent_id = null`):
- Свежеобжаренный кофе (`svezheobzharennyy-kofe`)
- Чай и кофейные напитки
- Продукция вендинга
- Здоровое питание

У каждой — 5–7 подкатегорий (например, у кофе: Африка, Йемен, Уганда, Эфиопия, Азия,
Центральная Америка, Латинская Америка). Дерево двухуровневое — подкатегорий у
подкатегорий сейчас нет, хотя схема (`parent_id` self-join) это бы позволила.

## Где используется

- `HomeController` — берёт **только** категории верхнего уровня
  (`Category::whereNull('parent_id')->get()`) для карточек на главной.
- `CatalogController` — та же выборка верхнего уровня переиспользуется для переключателя
  категорий над заголовком страницы каталога (см.
  [features/catalog-page.md](../features/catalog-page.md)); отдельно — дочерние категории
  конкретно открытой категории (`where('parent_id', $category->id)`), чтобы включить их
  товары в выдачу и показать как чекбоксы в сайдбаре фильтров.
- `components/category-card.blade.php` — карточка-ссылка `<a href="/catalog/{slug}">`,
  переиспользуется и на главной, и в переключателе на странице каталога.
