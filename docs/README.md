# Документация проекта

Это живая техническая документация coffee-tea-shop-Laravel13 — пояснения, как устроен
код: схема БД, связи между таблицами, как работают конкретные участки приложения.
Ведётся и обновляется при каждом изменении проекта (см. правило в `CLAUDE.md` в корне
репозитория, раздел «Ведение документации `docs/`»).

Это не то же самое, что:
- `CLAUDE.md` — правила работы ассистента (режимы наставника, этапы, что можно и нельзя).
- `.claude-docs/PROGRESS.md` — чек-лист выполнения этапов проекта (готово/не готово).

Здесь — только про то, **как код устроен и почему**, без привязки к прогрессу по этапам.

## Структура

### [database/](database/README.md) — схема БД и связи
- [Категории](database/categories.md) — дерево категорий, self-join
- [Товары и характеристики](database/products-and-properties.md) — Product, Property, пивот `product_properties`
- [Отзывы](database/reviews.md) — таблица `reviews`, счётчик `reviews_count`
- [Пользователи, корзина, заказы](database/users-baskets-orders.md) — User, Basket, Order (частично не реализовано)

### features/ — как работают конкретные участки приложения
- [Страница каталога](features/catalog-page.md) — маршрут → контроллер → view, переключатель категорий, фильтры
- [Пагинация](features/pagination.md) — кастомный view пагинации
- [Сидеры](features/seeders.md) — тестовые данные, порядок запуска, привязка характеристик к товарам

## Как это читать (для Сергея)
Если непонятно, как работает какой-то участок — смотри сюда раньше, чем в сам код: здесь
объяснена логика и связи, а не только «что где лежит». Ссылки между файлами ведут друг на
друга там, где тема пересекается (например, из `features/seeders.md` — на
`database/products-and-properties.md`, и обратно).
