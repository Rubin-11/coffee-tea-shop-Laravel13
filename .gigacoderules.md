# Project Context: Coffee & Tea Shop (Laravel)

## Project Stack
- **Framework:** Laravel 13.8 (PHP 8.3)
- **Docker:** PHP-FPM + Nginx + PostgreSQL 18
- **Testing:** Pest PHP
- **Package Manager:** Composer
- **Frontend:** Vite

## Project Structure
- Source code: `src/` (mounted to `/var/www` in Docker)
- Project root: `//wsl.localhost/Ubuntu/home/rubin11/projects/coffee-tea-shop-Laravel13`
- Namespace: `App\` → `src/app/`

## Docker Environment Rules
- **PHP Service:** `php`
- **Nginx Service:** `nginx`
- **Database Service:** `postgres`
- **Volumes:** `./src` → `/var/www`
- **Docker Compose:** `docker compose up -d` (from project root)
- **Composer Commands:** `docker compose exec php composer <command>`
- **Artisan Commands:** `docker compose exec php php artisan <command>`
- **User:** UID 1000 inside container (matches host user `rubin11`)
- **Network:** `app-network` (bridge)
- **Ports:** Nginx: `8080:80`, Postgres: `5432:5432`
- **Environment:** `.env` is at project root (outside `src`)

## Coding Standards
- **PHP:** Strictly typed, PSR-12, PHP 8.3+ features
- **Models:** Eloquent ORM, use casts, fillable, relationships
- **Controllers:** Thin controllers, business logic in Services or Actions
- **Database:** Always use migrations, seeds, factories
- **Views:** Blade templates, prefer component-based architecture
- **Routes:** `web.php` for web routes, proper naming

## Database
- **Driver:** PostgreSQL (via `pdo_pgsql`)
- **Database:** `laravel_db`
- **User:** `laravel_user`
- **Password:** `secret_password` (from docker-compose.yml)

## Testing
- Use **Pest PHP** (`docker compose exec php php artisan test`)
- Tests located in `src/tests/`
- Feature tests in `src/tests/Feature/`
- Unit tests in `src/tests/Unit/`

## File Permissions
- Files in `src/` belong to host user (UID 1000)
- PHP-FPM runs as UID 1000
- Storage/cache: `storage/` and `bootstrap/cache/` need write access (775)

## Important Notes
- ❌ Do NOT use `laravel new` — create files manually or copy from host
- ❌ Do NOT run Composer/Artisan outside Docker (PHP version conflict)
- ❌ Do NOT edit config files directly — use `.env`
- ✅ Always run tests after changes
- ✅ Use `docker compose exec php php artisan make:<command>` to generate files
